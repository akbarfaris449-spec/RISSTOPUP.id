ⓘ  Umum

Apa itu RISS TOP UP?

RISS TOP UP adalah layanan pembelian produk digital seperti top up game, pulsa, paket data, dan produk digital lainnya.

Bagaimana cara membeli produk?

Pilih kategori dan produk, pilih nominal, lengkapi data tujuan dan informasi kontak, periksa detail transaksi, lalu tekan tombol Lanjut Bayar.

Bagaimana cara melihat status transaksi?

Buka menu Cek Transaksi, masukkan ID Transaksi yang diberikan setelah checkout, lalu tekan Lacak Transaksi. Simpan ID Transaksi kamu.

🎮  Top Up

Berapa lama pesanan diproses?

Pesanan diproses setelah pembayaran diperiksa dan dikonfirmasi Admin. Waktu penyelesaian bergantung pada produk dan kondisi layanan.

Data apa yang harus diisi saat top up game?

Isi User ID, Player ID, Zone ID, Server ID, atau username sesuai petunjuk pada produk yang dipilih. Pastikan tidak ada kesalahan ketik.

Bagaimana jika salah memasukkan ID tujuan?

Segera hubungi Admin melalui WhatsApp dan sertakan ID Transaksi. Kesalahan data tujuan dapat memengaruhi keberhasilan pengiriman produk.

Pesanan belum masuk, apa yang harus dilakukan?

Periksa status transaksi terlebih dahulu. Jika sudah dikonfirmasi tetapi produk belum diterima, hubungi Admin dengan menyertakan ID Transaksi.

▤  Pembayaran

Metode pembayaran apa saja yang tersedia?

Pembayaran tersedia melalui DANA dan GoPay. Jika ingin membayar menggunakan QR, silakan minta QR kepada Admin melalui WhatsApp.

Bagaimana cara melakukan pembayaran?

Pilih DANA atau GoPay, salin nomor tujuan yang ditampilkan, lalu transfer sesuai total pembayaran pada detail transaksi.

Bagaimana cara mengirim bukti pembayaran?

Upload foto atau screenshot bukti transfer pada halaman pembayaran, kemudian tekan Kirim Bukti Pembayaran ke Firebase. Bukti akan tersimpan pada Firebase Storage dan status pesanan berubah menjadi Menunggu Konfirmasi.

Mengapa pembayaran saya belum dikonfirmasi?

Admin perlu memeriksa bukti transfer dan memastikan dana sudah diterima. Jangan mengirim pembayaran berulang sebelum menghubungi Admin.

▣  Pengembalian Dana

Bagaimana cara mengajukan pengembalian dana?

Hubungi Admin melalui WhatsApp, sertakan ID Transaksi, bukti pembayaran, dan alasan pengajuan agar dapat diperiksa.

Apakah semua transaksi bisa dikembalikan?

Pengajuan pengembalian dana akan diperiksa berdasarkan status dan kondisi transaksi. Admin akan memberikan informasi setelah pemeriksaan.

♢  Keamanan

Apakah saya perlu memberikan password akun?

Tidak. RISS TOP UP tidak meminta password akun game, email, atau media sosial. Jangan pernah membagikan password atau kode OTP.

Bagaimana menjaga keamanan transaksi?

Pastikan nama produk, nominal, ID tujuan, dan total pembayaran sudah benar sebelum melakukan transfer.

Apakah bukti pembayaran harus asli?

Ya. Kirim bukti transfer asli yang jelas dan tidak diedit agar Admin dapat memeriksanya.

Bagaimana menghubungi Admin resmi?

Gunakan tombol WhatsApp atau Telegram pada bagian bawah Pusat Bantuan. Jangan percaya nomor yang mengaku sebagai Admin di luar kontak resmi website.

Pertanyaan tidak ditemukan. Coba kata kunci lain atau hubungi Admin.
